---

Name these fields in the `fields` / `optionalFields` of a [data request](./data-requests.md). You can name up to 40 per request. Every name starts with `BUSINESS_`.

:::tip The live list is authoritative
The current vocabulary, including **which fields are PII** and **which pricing tier** each belongs to, is always available from the API:

```bash
curl https://auth.corepass.net/api/v1/kyb/pricing -H "Authorization: <YOUR_API_KEY>"
```
:::

| Group | Prefix | Entitlements |
| --- | --- | --- |
| Company facts, documents, verification state | `BUSINESS_` | `kyb:data-request` |
| Directors (PII) | `BUSINESS_DIRECTOR_` | `kyb:data-request` **and `kyb:pii`** |
| Beneficial owners / UBOs (PII) | `BUSINESS_UBO_` | `kyb:data-request` **and `kyb:pii`** |
| Declared (self-reported) fields | `BUSINESS_DECLARED_` | `kyb:data-request`, plus `kyb:pii` for director and UBO fields |

## Company facts

Verified against the company registry.

| Area | Fields |
| --- | --- |
| Identity | `BUSINESS_LEGAL_NAME`, `BUSINESS_TRADE_NAME`, `BUSINESS_REGISTRATION_NUMBER`, `BUSINESS_COMPANY_TYPE`, `BUSINESS_LEGAL_FORM` |
| Incorporation | `BUSINESS_INCORPORATION_COUNTRY`, `BUSINESS_INCORPORATION_DATE`, `BUSINESS_OPERATION_START_DATE` |
| Tax | `BUSINESS_TAX_ID`, `BUSINESS_VAT_NUMBER` |
| Addresses | `BUSINESS_LEGAL_ADDRESS`, `BUSINESS_POSTAL_ADDRESS`, `BUSINESS_ADDRESS_STREET`, `BUSINESS_ADDRESS_SUB_STREET`, `BUSINESS_ADDRESS_CITY`, `BUSINESS_ADDRESS_STATE`, `BUSINESS_ADDRESS_ZIP_CODE`, `BUSINESS_ADDRESS_COUNTRY` |
| Contact | `BUSINESS_WEBSITE`, `BUSINESS_EMAIL`, `BUSINESS_PHONE` |
| Activity and size | `BUSINESS_INDUSTRY_CODE`, `BUSINESS_INDUSTRY_DESCRIPTION`, `BUSINESS_REGISTERED_CAPITAL`, `BUSINESS_EMPLOYEES_NUMBER` |
| Licence | `BUSINESS_LICENSE_NUMBER`, `BUSINESS_LICENSE_ISSUED_ON`, `BUSINESS_LICENSE_VALID_UNTIL` |
| Registry | `BUSINESS_REGISTRY_STATUS`, `BUSINESS_REGISTRY_STATUS_COMMENT`, `BUSINESS_REGISTRY_SOURCE`, `BUSINESS_REGISTRY_SOURCE_URL`, `BUSINESS_REGISTRY_LAST_UPDATED` |

## Company documents

These fields return **verification verdicts about a document, never the file itself**:

`BUSINESS_INCORPORATION_DOCUMENT`, `BUSINESS_REGISTRY_EXTRACT_DOCUMENT`, `BUSINESS_ARTICLES_OF_ASSOCIATION_DOCUMENT`, `BUSINESS_SHAREHOLDER_REGISTRY_DOCUMENT`, `BUSINESS_PROOF_OF_ADDRESS_DOCUMENT`.

## Verification and service state

`BUSINESS_VERIFIED`, `BUSINESS_VERIFICATION_STATUS`, `BUSINESS_VERIFICATION_LEVEL`, `BUSINESS_VERIFIED_AT`, `BUSINESS_VERIFICATION_EXPIRES_AT`, `BUSINESS_REGISTRY_CHECKED_AT`, `BUSINESS_REGISTRY_ANSWER`, `BUSINESS_WALLET_ADDRESS`.

:::note Not answerable yet
These names are published in the vocabulary but can't be answered yet. Requesting them today returns nothing, and fields that aren't released aren't charged:

`BUSINESS_CNS_DOMAIN`, `BUSINESS_SANCTIONS_SCREENING`, `BUSINESS_PEP_SCREENING`, `BUSINESS_ADVERSE_MEDIA_SCREENING`, `BUSINESS_AML_VERDICT`, `BUSINESS_AML_DETAIL`, `BUSINESS_ONGOING_MONITORING`, `BUSINESS_UBO_SHARE_AMOUNT`.
:::

## Directors (PII)

Natural persons. **Requires `kyb:pii`.** Each director answers separately. See [Multiple people answering one field](./webhooks.md#multiple-people-answering-one-field).

`BUSINESS_DIRECTOR_NAME`, `BUSINESS_DIRECTOR_FIRST_NAME`, `BUSINESS_DIRECTOR_MIDDLE_NAME`, `BUSINESS_DIRECTOR_LAST_NAME`, `BUSINESS_DIRECTOR_DOB`, `BUSINESS_DIRECTOR_NATIONALITY`, `BUSINESS_DIRECTOR_COUNTRY`, `BUSINESS_DIRECTOR_POSITION`, `BUSINESS_DIRECTOR_ROLE`, `BUSINESS_DIRECTOR_STATUS`, `BUSINESS_DIRECTOR_APPOINTED_ON`, `BUSINESS_DIRECTOR_EMAIL`, `BUSINESS_DIRECTOR_PHONE`, `BUSINESS_DIRECTOR_CORRESPONDENCE_ADDRESS`, `BUSINESS_DIRECTOR_VERIFICATION_STATUS`.

## Beneficial owners / UBOs (PII)

Natural persons. **Requires `kyb:pii`.**

`BUSINESS_UBO_NAME`, `BUSINESS_UBO_FIRST_NAME`, `BUSINESS_UBO_MIDDLE_NAME`, `BUSINESS_UBO_LAST_NAME`, `BUSINESS_UBO_DOB`, `BUSINESS_UBO_NATIONALITY`, `BUSINESS_UBO_COUNTRY`, `BUSINESS_UBO_EMAIL`, `BUSINESS_UBO_PHONE`, `BUSINESS_UBO_TYPE`, `BUSINESS_UBO_STATUS`, `BUSINESS_UBO_DIRECT_OWNERSHIP_PERCENTAGE`, `BUSINESS_UBO_INDIRECT_OWNERSHIP_PERCENTAGE`, `BUSINESS_UBO_BENEFICIAL_OWNERSHIP_PERCENTAGE`, `BUSINESS_UBO_NATURE_OF_CONTROL`, `BUSINESS_UBO_DEGREE_OF_SEPARATION`, `BUSINESS_UBO_NOTIFIED_ON`, `BUSINESS_UBO_CORRESPONDENCE_ADDRESS`, `BUSINESS_UBO_VERIFICATION_STATUS`.

## Declared fields

Declared by the business itself and **never independently verified**. Use them when you want the business's own statement rather than a registry fact.

| Area | Fields |
| --- | --- |
| Company | `BUSINESS_DECLARED_LEGAL_NAME`, `BUSINESS_DECLARED_TRADE_NAME`, `BUSINESS_DECLARED_REGISTRATION_NUMBER`, `BUSINESS_DECLARED_REGISTRATION_LOCATION`, `BUSINESS_DECLARED_INCORPORATION_COUNTRY`, `BUSINESS_DECLARED_INCORPORATION_DATE`, `BUSINESS_DECLARED_COMPANY_TYPE`, `BUSINESS_DECLARED_CONTROL_SCHEME`, `BUSINESS_DECLARED_TAX_ID`, `BUSINESS_DECLARED_LEI_CODE`, `BUSINESS_DECLARED_APPLICANT_POSITION` |
| Addresses | `BUSINESS_DECLARED_LEGAL_ADDRESS`, `BUSINESS_DECLARED_POSTAL_ADDRESS`, `BUSINESS_DECLARED_ADDRESS_STREET`, `BUSINESS_DECLARED_ADDRESS_SUB_STREET`, `BUSINESS_DECLARED_ADDRESS_CITY`, `BUSINESS_DECLARED_ADDRESS_STATE`, `BUSINESS_DECLARED_ADDRESS_ZIP_CODE`, `BUSINESS_DECLARED_ADDRESS_COUNTRY` |
| Contact | `BUSINESS_DECLARED_WEBSITE`, `BUSINESS_DECLARED_EMAIL`, `BUSINESS_DECLARED_PHONE` |
| Directors (PII) | `BUSINESS_DECLARED_DIRECTOR_FIRST_NAME`, `BUSINESS_DECLARED_DIRECTOR_MIDDLE_NAME`, `BUSINESS_DECLARED_DIRECTOR_LAST_NAME`, `BUSINESS_DECLARED_DIRECTOR_DOB`, `BUSINESS_DECLARED_DIRECTOR_NATIONALITY`, `BUSINESS_DECLARED_DIRECTOR_COUNTRY`, `BUSINESS_DECLARED_DIRECTOR_POSITION`, `BUSINESS_DECLARED_DIRECTOR_EMAIL`, `BUSINESS_DECLARED_DIRECTOR_PHONE` |
| UBOs (PII) | `BUSINESS_DECLARED_UBO_FIRST_NAME`, `BUSINESS_DECLARED_UBO_MIDDLE_NAME`, `BUSINESS_DECLARED_UBO_LAST_NAME`, `BUSINESS_DECLARED_UBO_DOB`, `BUSINESS_DECLARED_UBO_NATIONALITY`, `BUSINESS_DECLARED_UBO_COUNTRY`, `BUSINESS_DECLARED_UBO_EMAIL`, `BUSINESS_DECLARED_UBO_PHONE`, `BUSINESS_DECLARED_UBO_DIRECT_OWNERSHIP_PERCENTAGE` |

## Retired names

These names were removed and are rejected with `422 retired_field`: `BUSINESS_REGISTRATION_LOCATION`, `BUSINESS_CONTROL_SCHEME`, `BUSINESS_LEI_CODE` (use the `BUSINESS_DECLARED_*` counterparts), `BUSINESS_DECLARED_DIRECTOR_NAME`, `BUSINESS_DECLARED_UBO_NAME`, `BUSINESS_DECLARED_UBO_INDIRECT_OWNERSHIP_PERCENTAGE`, `BUSINESS_DECLARED_UBO_NATURE_OF_CONTROL`.
